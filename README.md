
# Magical Harry Potter Diorama 🎁✨

## A Unique Birthday Gift for a Harry Potter Fan

This project is a handcrafted diorama that captures a magical scene from the Harry Potter universe. It combines 3D-printed elements, an IKEA "BEGÅVNING" display case, and a custom-built lighting system powered by an Arduino Nano. Perfect as a decorative piece with a little extra magic, the diorama includes interactive lighting features that respond to the environment.

### 🛠️ Features
- **Dynamic Lighting System**: A sensor detects ambient light and adjusts the brightness of the diorama to simulate different times of day.
  - A flickering LED mimics the effect of a real torch.
  - A soft nightlight illuminates the house at night.
  
- **Automatic Day/Night Detection**: The system uses an algorithm to check background light levels and activates the nightlight when evening falls.
  
- **Energy Efficiency**: The lighting system has a cooldown period to save battery power and reduce annoying flickering effects.

### Components
- **IKEA "BEGÅVNING" Display Case**: Used as the frame for the diorama.
- **3D-Printed Elements**: Custom-printed to represent iconic elements from the Harry Potter world.
- **Arduino Nano**: Controls the lighting and sensor systems.
- **Custom Lighting**: A combination of flickering and steady LEDs that bring the scene to life.

### How to Build
1. 3D print the diorama components.
2. Assemble the lighting system using an Arduino Nano, LED lights, and a light sensor.
3. Program the Arduino Nano with the provided code in this repository.
4. Place everything inside the "BEGÅVNING" display case for a complete look.

### Getting Started with the Code
This repository contains the code that runs on the Arduino Nano. To get started:
1. Upload the code to the Arduino Nano.
2. Connect the light sensor and LEDs according to the wiring diagram.
3. Power the system and watch the magic unfold!
